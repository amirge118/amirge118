# Hi there, I'm Amir Gefen 👋

### Senior Backend Engineer | Distributed Systems | Cloud-Native AWS | AI Agents

I am a Senior Backend Engineer with 5+ years of experience building scalable, cloud-native, and data-intensive systems.

I enjoy taking complex backend problems from architecture and implementation through deployment, monitoring, and long-term ownership. My work spans production microservices, event-driven systems, AWS infrastructure, and practical AI-powered engineering automation.

Beyond code, I believe in continuous growth and balance. I enjoy exploring how AI and automation can simplify complex engineering work and leave more room for creative thinking.

- 🔭 **What I Do:** I design and build reliable backend services, REST APIs, distributed systems, and data pipelines. I enjoy understanding how data flows, how systems behave under load, and how to keep them maintainable as requirements grow.

- ⚡ **Systems & Data:** I have worked with high-throughput, event-driven architectures using Kafka, ClickHouse, and Cassandra, including asynchronous processing, retries, backpressure, and production debugging.

- 🤖 **AI & Automation:** I build LLM-powered agents and engineering workflows using LangChain, LangGraph, and Model Context Protocol (MCP), including tools for code analysis, modernization, refactoring, and test generation.

- 🧘 **My Values:** Ownership, continuous learning, clear communication, and building solutions that are useful beyond the first deployment.

- 🏀 **Fun Fact:** When I'm not working on backend systems, you'll probably find me playing basketball, practicing yoga, or heading to the beach.
